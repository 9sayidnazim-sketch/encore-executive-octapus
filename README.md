# Encore Executive Travel | Octapus

Chauffeur website built with React, TanStack Start, Tailwind CSS and Nitro.

## Development

Use Node.js 22.12+ or 24. Run `npm ci`, then `npm run dev`.

## Verification

Run `npm run typecheck`, `npm test`, `npm run lint`, and `npm run build`.

## Deployment

Vercel builds with `npm run build`; Nitro generates the server output.

Booking and contact forms prepare a WhatsApp enquiry. Customers must send it in WhatsApp; Encore must confirm the booking. No payment or booking backend is included.
